# Contributing

We welcome contributions to keep this repository up-to-date!

## Adding a New Paper

Please open a pull request with the following format:

```markdown
- **Paper Title**  
  *Author1 et al.* [Venue Year]  
  [[Paper]](link) [[Code]](link)
```

### Guidelines

1. Place the paper in the correct **architectural category** (CNN, Transformer, Mamba, SAM, etc.)
2. Include a link to the **paper** (prefer arXiv or official publisher)
3. Include a link to the **code** if publicly available
4. Keep entries sorted **chronologically** within each subsection
5. Only include papers related to **medical image segmentation**

## Adding a New Dataset

Add a row to the Benchmarks table:

```markdown
| **Dataset Name** | Modality | Task Description | [[Access]](link) |
```

## Reporting Issues

If you find broken links, incorrect citations, or misclassified papers, please open an issue.

Thank you for helping the community!
